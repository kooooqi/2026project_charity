# 2026 Project - 기부 웹사이트

현대적이고 반응형 기부 웹사이트입니다. 사용자 친화적인 인터페이스로 기부를 쉽게 할 수 있도록 설계되었습니다.

## 기능

✨ **주요 기능:**
- 반응형 디자인 (모바일, 태블릿, 데스크톱)
- 매끄러운 스크롤 네비게이션
- 기부 금액 선택 버튼
- 기부자 정보 입력 폼
- 임팩트 통계 표시
- 접근성 최적화

## 페이지 구성

1. **히어로 섹션** - 첫 인상과 CTA 버튼
2. **소개** - 기관의 미션 설명
3. **기부** - 기부 양식 (이름, 이메일, 금액, 메시지)
4. **임팩트** - 성과 통계
5. **연락처** - 문의 정보

## 기술 스택

- HTML5
- CSS3 (Flexbox, Grid, 애니메이션)
- Vanilla JavaScript
- 반응형 웹 디자인

## 호스팅

이 사이트는 **GitHub Pages**로 호스팅됩니다.

**접속 주소:** `https://kooooqi.github.io/2026project_charity/`

## 설정 방법

1. GitHub 저장소 Settings에서 Pages 활성화
2. Source를 `main` 브랜치로 설정
3. 저장 후 자동 배포

## 파일 구조

```
2026project_charity/
├── index.html      # 메인 HTML 파일
├── styles.css      # 스타일시트
├── script.js       # JavaScript 기능

```

## 사용자 상호작용

- **금액 선택:** 빠른 선택 버튼 또는 직접 입력
- **폼 제출:** 기부 정보 입력 후 제출
- **네비게이션:** 부드러운 스크롤로 섹션 이동

## 커스터마이징

- 색상 변경: `styles.css`의 `:root` CSS 변수 수정
- 기부 금액: `index.html`의 `data-amount` 속성 수정
- 연락처 정보: `index.html`의 contact 섹션 수정
